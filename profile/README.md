# woodruffw-trough

This organization is where [@woodruffw] puts his slop.

## What is slop?

For the purpose of this organization, "slop" is code that's produced wholly by
LLMs, with only human oversight.

That means that most (all?) of the code in this organization has not been read
by a human. Instead, a human ([@woodruffw]) guided an LLM to write it.

## Who controls this?

[@woodruffw] administrates this organization. 

[@woodruffw-bot] is his proxy. It works on his behalf.

## How should I consume this organization's repos?

You probably shouldn't, at least not directly.

In general, the idea behind this organization is twofold:

1. Projects get incubated here until they are no longer slop,
   at which point they get "promoted" to somewhere else.
   Promotion doesn't mean that the code was human-reviewed;
   it means I ([@woodruffw]) feel confident enough in it
   for my own purposes.
2. Projects stay here if they will never _not_ be slop.
   For example, "personal software" doesn't really need to
   be anywhere else, so it stays here.
